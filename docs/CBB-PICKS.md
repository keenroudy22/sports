# Sourced CBB straight decisions

The November3 owner request enables a reviewed main-line CBB decision path. It is
not promotion of hoops-v1, a probability model, player props, Chef's Picks or a
Climb adapter. It does not require a daily pick or infer value from exhibitions.

Use scripts/cbb_picks.py --spec PATH for a read-only refusal/preview and --admit
through the normal configured wrapper for an approved exact quote. The caller
must supply the current stored CBB game, selectionMethod sourced-cbb-straight-v1,
full_game period, alternate false, a main spread or total with exact opposite
price, ordinary1u policy, visible DraftKings receipt, current both-team facts,
availability review, reason and countercase. The quote and decision must be no
older than one hour. No chance/fairOdds/expectedValue/calibrated fields are allowed.
Fixture identity must match the current stored slate. Shared exposure includes
CBB in both directions; settlements do not replenish the day's reservation.

The append-only data/cbb-picks ledger preserves original terms and original
review. Grade corrections append rather than replace. Existing desk runs grade
against received official CBB finals and prepare cards; existing social and
five-minute Discord workers consume already-reviewed stored evidence, with no
additional feed calls. X retains the free account allowance, backoff, posting
caps, spacing, live-card and caption checks. Ambiguous sends require reconciliation.
A local admission is not an X or Discord receipt. CBB picks and original-price
results have their own Today/Record section, separate from football, fun tickets,
Climbs and model accuracy. Public data omits private quote receipt paths.

Current implementation supports an attended, sourced review. It is not an
unattended research agent that independently discovers and approves new bets.
Existing daily research must prepare an actual sourced spec; no fabricated
healthy status, observation clock, probability or automatic model promotion.
